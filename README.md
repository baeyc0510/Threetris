# TETRIS 3D

브라우저와 Windows 데스크톱에서 즐기는 3D 테트리스입니다. 네온 신스웨이브 스타일의 3D 우물 안에 테트로미노를 배치하고, 한 줄이 아니라 **수평층 전체**를 채워 클리어합니다.

이 프로젝트는 Vite, TypeScript, Three.js와 HTML/CSS 오버레이로 구현되었습니다. 게임 로직은 정수 그리드가 담당하고, Three.js 렌더러는 그 상태를 시각화합니다.

## 주요 기능

- 기본 5×5×20 3D 보드와 7×7, 9×9, 11×11 보드 선택
- I, O, T, S, Z, J, L 7종 테트로미노와 7-bag 랜덤 생성
- X/Y/Z축 기준 90도 회전
- 카메라 기준 방향키 이동과 DAS/ARR 반복 입력
- Face / Corner 카메라 모드와 Q/E 카메라 회전
- NEXT 5개 미리보기, HOLD, 고스트 조각
- 하드 드롭, 소프트 드롭, 락 딜레이, 스핀 보너스
- 수평층 클리어, 콤보, Back-to-back, 레벨 및 중력 속도 상승
- Menu, Settings, Playing, Paused, Game Over 상태
- WebAudio 아케이드 효과음과 층 클리어 네온 이펙트
- 브라우저 `localStorage` 기반 설정 및 난이도별 기록 저장

## 실행 환경

### 브라우저 개발 모드

Node.js가 설치된 개발 환경에서 실행합니다.

```bash
npm install
npm run dev
```

Vite 개발 서버가 실행되고 브라우저가 자동으로 열립니다.

### 프로덕션 빌드

```bash
npm run typecheck
npm run build
npm run preview
```

`npm run build`는 TypeScript 타입 검사 후 `dist/`에 정적 빌드 결과를 생성합니다. `npm run preview`는 그 결과를 로컬에서 확인하는 명령입니다.

### Windows portable EXE

Node.js, npm, 서버 없이 실행할 수 있는 Electron portable EXE를 만듭니다.

```bash
npm install
npm run desktop:package
```

생성 파일:

```text
release/TETRIS-3D-Portable-1.0.0.exe
```

생성된 `.exe`는 Windows x64 PC에서 더블클릭으로 실행됩니다. `win-unpacked/` 폴더는 개발·검사용 중간 산출물입니다.

## 게임 조작

### 플레이 중

| 동작 | 입력 | 설명 |
|---|---|---|
| 수평 이동 | 방향키 | 현재 카메라 기준으로 이동 |
| 조각 눕히기 | W / S | 화면 안쪽 또는 앞쪽 방향으로 회전 |
| 좌우 회전 | A / D | 수직축 기준 회전 |
| 카메라 회전 | Q / E | 보드 바깥 레일을 따라 회전 |
| 하드 드롭 | Space | 즉시 착지 및 고정 |
| 소프트 드롭 | Shift | 낙하 속도 증가 |
| 홀드 | C | 현재 조각 보관 또는 보관 조각과 교체 |
| 일시정지 | P / Esc | 게임 일시정지 |
| 재시작 | R | 현재 보드에서 새 게임 시작 |

홀드는 조각이 고정될 때까지 한 번만 사용할 수 있습니다. 방향키를 누르고 있으면 DAS/ARR에 따라 자동 반복 이동합니다.

### 메뉴와 설정

| 동작 | 입력 |
|---|---|
| 메뉴 이동 | 방향키 |
| 선택 | Enter |
| 뒤로 / 일시정지 해제 | Esc |

Settings에서 보드 크기, 카메라 모드, 사운드를 변경할 수 있습니다. Face 카메라는 기본값이며, Corner 카메라는 3D 깊이를 보기 좋습니다. HUD의 `COMPASS` 패널은 현재 시점에서 방향키가 조각을 화면 어느 방향으로 이동시키는지 보여줍니다.

## 게임 규칙

### 보드와 조각

- 보드의 보이는 영역은 5×5×20입니다.
- 조각 스폰을 위한 숨겨진 4층을 포함해 내부적으로는 24층을 사용합니다.
- 보드는 `grid[z][y][x]` 정수 그리드로 처리됩니다.
- 모든 조각은 네 개의 큐브로 이루어진 테트로미노입니다.

### 층 클리어

고정된 Z층의 모든 X/Y 셀이 채워지면 해당 수평층을 삭제합니다. 위에 있던 층은 아래로 내려오며, 여러 층이 동시에 가득 차면 한 번에 처리합니다. 행, 열 또는 일반 2D 라인 클리어는 사용하지 않습니다.

### 점수와 레벨

기본 층 클리어 점수는 다음과 같습니다.

| 클리어 층 수 | 기본 점수 |
|---:|---:|
| 1층 | 100 |
| 2층 | 300 |
| 3층 | 600 |
| 4층 | 1000 |

4층을 초과하면 추가 층마다 400점이 더해집니다. 점수에는 레벨 배율, 콤보, Back-to-back, 스핀, 하드 드롭 및 소프트 드롭 점수가 반영됩니다. 5층을 클리어할 때마다 레벨이 오르고 낙하 간격이 짧아집니다.

새 조각을 스폰할 수 없으면 Game Over가 됩니다.

## 저장 데이터

브라우저 또는 Electron 앱의 `localStorage`에 다음 정보를 저장합니다.

- 보드 크기별 최고 점수
- 보드 크기별 최고 생존 시간
- 총 플레이 시간
- 보드 크기, 카메라 모드, 사운드 설정

## 기술 구조

| 영역 | 역할 |
|---|---|
| `src/core/` | 보드, 조각, 충돌, 회전, 낙하, 클리어, 점수, 저장 등 순수 게임 로직 |
| `src/render/` | Three.js 씬, 카메라, 인스턴스 큐브, 고스트, bloom 및 이펙트 |
| `src/input/` | 키보드 입력, DAS/ARR, 카메라 기준 이동, 메뉴 입력 |
| `src/ui/` | 메뉴, 설정, HUD, 일시정지, Game Over HTML/CSS 오버레이 |
| `src/audio/` | WebAudio 기반 효과음 |
| `electron/` | 로컬 빌드 결과를 서버 없이 여는 Windows 데스크톱 셸 |

게임 로직과 렌더링은 분리되어 있습니다. 충돌, 회전, 층 클리어, 점수, Game Over 판정은 Three.js 메시가 아니라 정수 그리드를 기준으로 처리합니다.
